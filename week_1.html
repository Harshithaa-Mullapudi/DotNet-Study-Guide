1. Introduction to .NET

.NET is a software development platform/ecosystem. It provides runtimes, libraries, tools and frameworks for building, running and deploying applications.

.NET vs C#

C# is a programming language. .NET is the platform/ecosystem that provides the runtime, libraries, SDK and application frameworks used to build and run applications.

Simple mental model

C# = language
.NET = platform
CLR = runtime
ASP.NET Core = web framework
EF Core = ORM

Features of .NET

  • Cross-platform: modern .NET runs on Windows, Linux and macOS.
  • Open source: much of the .NET platform is developed openly.
  • High performance: optimized runtime and libraries.
  • Automatic memory management: Garbage Collector manages managed memory.
  • Type safety: C# and the runtime help detect invalid type operations.
  • Rich libraries: collections, I/O, networking, JSON, threading, dates and more.
  • Multiple application models: web, APIs, desktop, mobile, cloud, background services and more.

Applications you can build

Console

Command-line programs and learning projects.

ASP.NET Core

Web APIs, MVC, Razor Pages, Minimal APIs, SignalR.

Desktop

Windows applications such as WinForms and WPF.

.NET MAUI

Cross-platform native UI applications.

Blazor

Interactive web UI using .NET/C#.

Cloud / Services

Microservices, workers, cloud applications and background services.

.NET Framework vs modern .NET

.NET Framework is the older Windows-focused implementation. .NET Core introduced a modern, cross-platform implementation; it evolved into the unified .NET 5+ platform. Today, “.NET” generally refers to the modern platform.

      ↓

      ↓

      ↓

      ↓

Source code

.cs files contain C# source code written by the developer.

Roslyn

The modern C# compiler. It translates C# source code into intermediate language (IL) and metadata.

IL / CIL / MSIL

CPU-independent intermediate instructions. The runtime can compile them to native machine code for the target environment.

Assembly

A compiled unit such as a .dll or .exe. It contains IL, metadata and possibly resources.

Metadata

Information describing types, methods, properties, parameters, references and assembly information.

JIT

Just-In-Time compiler converts IL into native machine code at runtime. Modern .NET also supports technologies such as ReadyToRun and Native AOT, but JIT is the foundational model to understand.

Common commands

dotnet restore   # restore dependencies
dotnet build     # compile/build project
dotnet run       # build if necessary, then run
dotnet clean     # remove build outputs
dotnet publish   # create deployment-ready output
Build vs Publish: Build creates build output for development/building. Publish prepares an application and its dependencies for deployment.

{

6C · Casting & conversion

double price = 99.99;
int value = (int)price;       // 99

double x = 5.0 / 2;           // 2.5
int y = 5 / 2;                // 2

int number = int.Parse("100");

if (int.TryParse("123", out int result))
{
    Console.WriteLine(result);
}

Implicit: safe compatible conversion handled automatically. Explicit: you specify the cast. TryParse: preferred for user input validation.

Boxing & unboxing

int number = 10;
object boxed = number;   // boxing

int value = (int)boxed;  // unboxing

Boxing wraps a value type as an object; unboxing extracts the contained value type and requires the correct type.

Important: (int)99.99 produces 99. Convert.ToInt32(99.99) rounds according to Convert's rules and produces 100 in this example.

7. Loops, Arrays & Memory

for

for (int i = 0; i < 5; i++)
{
    Console.WriteLine(i);
}

while

while (condition)
{
    // repeat while condition is true
}

do-while

do
{
    // executes at least once
}
while (condition);

foreach

foreach (Student student in students)
{
    Console.WriteLine(student.Name);
}

Nested loops are loops inside loops. A reverse loop can decrement the index. You can control step size with i += 2, etc.

Arrays

An array is a fixed-size, zero-based collection of elements of one type.

int[] numbers = { 10, 20, 30 };

Console.WriteLine(numbers[0]);
Console.WriteLine(numbers.Length);

Multidimensional arrays

int[,] matrix =
{
    { 1, 2 },
    { 3, 4 }
};

matrix.GetLength(0); // rows
matrix.GetLength(1); // columns

Jagged arrays

int[][] values =
{
    new[] { 1, 2 },
    new[] { 3, 4, 5 }
};

Memory mental model

  • Variables hold values or references.
  • Reference variables can point to objects managed by the .NET runtime.
  • The Garbage Collector automatically reclaims managed objects that are no longer reachable.
  • Arrays and class objects are reference types.
  • Copying a reference normally copies the reference, not the entire object.

Shallow vs deep copy

Shallow copy: top-level object is copied but referenced nested objects may still be shared. Deep copy: nested object graph is copied so the new object does not share those mutable nested references.

8. Methods

Basic method structure

static int Add(int a, int b)
{
    return a + b;
}

int result = Add(10, 20);

Parameters are variables in the method declaration. Arguments are the actual values supplied during invocation.

void

static void Display()
{
    Console.WriteLine("Hello");
}

A void method does not return a value.

Method overloading

static int Add(int a, int b) => a + b;
static int Add(int a, int b, int c) => a + b + c;
static double Add(double a, double b) => a + b;

Overloads differ by parameter number, type, or order. Return type alone cannot overload a method.

Pass by value

C# passes arguments by value by default. For a reference-type argument, the reference itself is copied by value, so both variables can refer to the same object.

ref

static void Increase(ref int value)
{
    value++;
}

int x = 10;
Increase(ref x); // x becomes 11

The caller must initialize the variable before passing it with ref.

out

static void GetValues(out int x)
{
    x = 100;
}

GetValues(out int value);

The caller doesn't need to initialize the variable first. The called method must assign it before returning.

in

in passes a variable by readonly reference. The called method can read it but should not modify it through that parameter.

params

static int Add(params int[] numbers)
{
    int total = 0;
    foreach (int n in numbers) total += n;
    return total;
}

Add(1, 2, 3, 4);

params allows a variable number of arguments and is represented as an array inside the method.

9. Object-Oriented Programming (OOP)

Class & object

A class is a blueprint/type. An object is an instance created from that class.

class Student
{
    public int Id { get; set; }
    public string Name { get; set; }

    public void Display()
    {
        Console.WriteLine(Name);
    }
}

Student student = new Student();

Members

  • Field: variable declared in a type.
  • Property: controlled access to data, usually with get/set accessors.
  • Method: behavior/action.
  • Constructor: initializes an object when it is created.

Constructor

public Student(int id, string name)
{
    Id = id;
    Name = name;
}

A constructor has the same name as the class and no return type. Constructors can be overloaded.

Access modifiers

Encapsulation

Bundling data and behavior together and controlling how internal state is accessed or changed.

Inheritance

class Animal
{
    public void Eat() { }
}

class Dog : Animal
{
}

C# classes support single class inheritance. A class can implement multiple interfaces. Common forms: single, multilevel and hierarchical inheritance.

Polymorphism

Compile-time: method overloading. Runtime: overriding through virtual/override.

class Animal
{
    public virtual void Speak() => Console.WriteLine("Animal");
}

class Dog : Animal
{
    public override void Speak() => Console.WriteLine("Bark");
}

virtual allows a derived class to override a member. override provides the derived implementation.

Abstraction

Expose what an object does while hiding unnecessary implementation details.

abstract class Shape
{
    public abstract double Area();
}

An abstract class cannot be instantiated directly. Abstract members have no implementation in the abstract class and must be implemented by a concrete derived class.

Interfaces

interface IPrintable
{
    void Print();
}

class Student : IPrintable
{
    public void Print()
    {
        Console.WriteLine("Student");
    }
}

An interface defines a contract/capability. A class can implement multiple interfaces.

Abstract class vs interface

Abstract classInterface

Enum

enum Status
{
    Active,   // 0
    Inactive  // 1
}

Status current = Status.Active;

Enums provide named constants. You can assign explicit underlying values.

11. Exception Handling

An exception is an object representing an error/unexpected condition that occurs during execution.

Compile-time error vs runtime exception

A compile-time error prevents successful compilation. A runtime exception occurs while a compiled program is executing.

Hierarchy

System.Exception
├── System.SystemException
│   ├── FormatException
│   ├── DivideByZeroException
│   ├── NullReferenceException
│   ├── IndexOutOfRangeException
│   ├── InvalidOperationException
│   └── ...
└── IOException
    └── FileNotFoundException
        ...

try / catch / finally

try
{
    int age = int.Parse(input);
}
catch (FormatException ex)
{
    Console.WriteLine("Invalid number format.");
}
finally
{
    Console.WriteLine("Cleanup/finalization work.");
}
  • try: code that may throw.
  • catch: handles matching exceptions.
  • finally: cleanup code that normally runs whether an exception occurred or not.

Multiple catch blocks

Put more specific exception types before broader types such as Exception.

Exception object

catch (Exception ex)
{
    Console.WriteLine(ex.Message);
    Console.WriteLine(ex.GetType());
    Console.WriteLine(ex.StackTrace);
    Console.WriteLine(ex.InnerException);
}

throw

if (age < 0)
{
    throw new ArgumentException("Age cannot be negative.");
}

throw; rethrows the current exception while preserving the original stack trace. throw ex; can reset the stack-trace origin and is generally avoided when rethrowing.

Exception filters

catch (Exception ex) when (ex.Message.Contains("Student"))
{
    // handle only matching exceptions
}

Custom exceptions

class StudentNotFoundException : Exception
{
    public StudentNotFoundException(string message)
        : base(message) { }
}

TryParse vs exceptions

Expected invalid user input should normally be validated with TryParse rather than using exceptions as normal control flow.

12. Collections

Collections store and manage multiple values/objects.

Array vs collection

An array has fixed size. Many collection types are designed to grow/shrink dynamically.

Generic vs non-generic

Generic: type-safe, e.g. List<Student>. Non-generic: older object-based collections such as ArrayList and Hashtable. Generic collections are preferred for normal modern code.

Common namespaces

System.Collections contains older non-generic collections. System.Collections.Generic contains generic collections.

List<T>

List names = new();

names.Add("A");
names.Add("B");
names.Remove("A");
names.RemoveAt(0);

int count = names.Count;
int capacity = names.Capacity;

Count = number of actual elements. Capacity = current internal storage available before another resize may be needed. Capacity is not a permanent maximum.

Dictionary<TKey,TValue>

Dictionary students = new();

students[1] = "Harshitha";
students[2] = "Rahul";

if (students.TryGetValue(1, out string? name))
{
    Console.WriteLine(name);
}

Keys are unique; values can repeat. TryGetValue safely checks for a key and outputs its value when found.

Queue<T> — FIFO

Queue queue = new();
queue.Enqueue("A");
queue.Enqueue("B");

queue.Dequeue(); // A

Stack<T> — LIFO

Stack stack = new();
stack.Push("A");
stack.Push("B");

stack.Pop(); // B

HashSet<T>

Stores unique values; useful when uniqueness is important.

SortedSet<T>

Unique values maintained in sorted order.

LinkedList<T>

Linked nodes. Useful when you specifically need linked-list semantics and efficient insertion/removal around known nodes; it is not automatically faster than List<T>.

SortedDictionary / SortedList

Both maintain key-value data sorted by key, with different internal data structures and performance characteristics.

Older non-generic collections

ArrayList, Hashtable, non-generic Queue, and non-generic Stack are older alternatives. They usually require more casting and can cause boxing for value types.

13. Delegates

A delegate is a type that can hold a reference to one or more compatible methods. It allows methods to be treated like values: stored, passed, returned and invoked.

Why delegates?

They allow us to pass behavior/methods around. This enables callbacks, custom sorting, events and LINQ operations.

Declaration → assignment → invocation

delegate void MyDelegate();

static void SayHello()
{
    Console.WriteLine("Hello");
}

MyDelegate del = SayHello;
del();

SayHello is a method group/reference that can be converted to a compatible delegate. SayHello() actually invokes the method immediately.

Method compatibility

The method must have a compatible return type and parameter list with the delegate. If it is incompatible, you normally get a compile-time error rather than a runtime exception.

Passing delegates

static void Execute(Action action)
{
    action();
}

Execute(SayHello);

The method is passed to Execute, and Execute decides when to invoke it.

Returning delegates

static Action GetAction()
{
    return SayHello;
}

Multicast delegates

Action action = Hello;
action += Goodbye;
action -= Hello;

action();

+= adds a method to the invocation list. -= removes a method.

Built-in delegates

TypePurposeExample
ActionReturns void, no parametersAction a = Hello;
Action<T>Returns void, accepts parametersAction<int>
Func<...>Returns a value; last generic type is return typeFunc<int,int>
Predicate<T>Accepts T and returns boolPredicate<int>
Action greet = Greet;
Func square = Square;
Predicate isEven = n => n % 2 == 0;

Callbacks

A callback is when a method is passed to another method and called later.

Delegates + sorting

numbers.Sort((a, b) => a.CompareTo(b));

Delegates + RemoveAll

numbers.RemoveAll(n => n % 2 != 0);

Delegates + events

Events use delegates to notify subscribed methods.

Delegates + LINQ

LINQ methods commonly accept delegate-based behavior, often supplied through lambda expressions.

14. LINQ

LINQ = Language Integrated Query. It provides a consistent way to query, filter, sort, transform, group and aggregate data.

Lambda expression

x => x * 2
x => x > 10
s => s.Age >= 18

Read s => s.Age >= 18 as “take a student s and check whether their age is at least 18.”

Filtering — Where

var adults = students.Where(s => s.Age >= 18);
var gradeA = students.Where(s => s.Grade == "A");

Projection — Select

var names = students.Select(s => s.Name);
Where = Which items?   Select = What from each item?

Sorting

students.OrderBy(s => s.Age);
students.OrderByDescending(s => s.Age);
students.OrderBy(s => s.Grade).ThenBy(s => s.Name);

Finding

MethodBehavior
FirstFirst match; throws if none
FirstOrDefaultFirst match or default
SingleExactly one match expected; throws for zero or multiple
SingleOrDefaultZero or one allowed; throws for multiple

Any / All

students.Any(s => s.Age > 20);
students.All(s => s.Age >= 18);

Any asks whether at least one matches. All asks whether every element matches.

Aggregation

students.Count();
students.Sum(s => s.Age);
students.Average(s => s.Age);
students.Min(s => s.Age);
students.Max(s => s.Age);

Distinct / Contains

var grades = students.Select(s => s.Grade).Distinct();
bool exists = numbers.Contains(5);

Skip / Take

var page = students
    .Skip(10)
    .Take(10);

Pagination formula: Skip((pageNumber - 1) * pageSize).Take(pageSize).

GroupBy

var groups = students.GroupBy(s => s.Grade);

This creates groups based on a key such as Grade.

ToList / ToArray

var result = students
    .Where(s => s.Age >= 18)
    .ToList();

These materialize the sequence into a concrete collection.

Method syntax vs query syntax

// Method syntax
var result = students
    .Where(s => s.Age >= 18)
    .OrderBy(s => s.Name);

// Query syntax
var result =
    from s in students
    where s.Age >= 18
    orderby s.Name
    select s;

Deferred execution

Many LINQ queries are evaluated when the sequence is enumerated rather than when the query expression is created.

var result = students.Where(s => s.Age >= 18);

// execution occurs when enumerated:
foreach (var s in result) { }

// or materialized:
var list = result.ToList();

LINQ + IEnumerable

LINQ commonly operates over IEnumerable<T> for in-memory sequences. This connects directly to the collection topic.

StudentAPI examples

public List<Student> GetAdultStudents()
{
    return students
        .Where(s => s.Age >= 18)
        .ToList();
}

public Student? GetStudentById(int id)
{
    return students.FirstOrDefault(s => s.Id == id);
}

public List<string> GetStudentNames()
{
    return students.Select(s => s.Name).ToList();
}

Management service using List + LINQ

class StudentService
{
    private readonly List<Student> students = new();

    public void AddStudent(Student student)
    {
        students.Add(student);
    }

    public List<Student> GetStudents()
    {
        return students;
    }

    public Student? GetStudentById(int id)
    {
        return students.FirstOrDefault(s => s.Id == id);
    }

    public List<Student> GetStudentsByGrade(string grade)
    {
        return students
            .Where(s => s.Grade == grade)
            .ToList();
    }

    public bool RemoveStudent(int id)
    {
        Student? student = GetStudentById(id);

        if (student == null)
            return false;

        students.Remove(student);
        return true;
    }
}

16. Debugging & Revision

Debugging basics

  • Set a breakpoint on a line where you want execution to pause.
  • Step Over executes the current line without entering called methods.
  • Step Into enters a called method.
  • Step Out finishes the current method and returns to its caller.
  • Inspect variables using Locals, Watch and hover/debug windows.
  • Use the Call Stack to understand how execution reached the current method.

Debugging questions to ask

  1. What value did I expect?
  2. What value did I actually get?
  3. Where did it first become wrong?
  4. Which method changed it?
  5. Is the issue input, condition, loop, collection, null, exception or state?

Common beginner mistakes

MistakeCorrect idea
“C# and .NET are the same”C# is a language; .NET is the platform.
“var means dynamic”var uses compile-time type inference.
“All value types are on stack”Storage depends on context.
“Array = ArrayList”Array is fixed-size; ArrayList is an older non-generic collection.
“Count is capacity”Count = elements; Capacity = allocated internal list storage.
“out must be initialized”out does not require caller initialization; method must assign it.
“ref is same as out”ref requires caller initialization; out does not.
“throw ex preserves stack exactly”Use bare throw to rethrow and preserve original stack trace.
“FirstOrDefault always returns null”It returns default(T); for reference types this is usually null.
“Select filters”Select transforms/projects; Where filters.
“Func always has parameters”Func can have zero or more inputs; last generic parameter is return type.

🧠 Week 1 Recall Quiz

Try answering before opening each answer. The goal is recall, not recognition.

1. What is .NET? What is C#?
.NET is a development platform/ecosystem; C# is a programming language commonly used with .NET.
2. What does CLR do?
It provides the runtime environment for managed .NET code, including JIT, garbage collection and other runtime services.
3. Explain C# → IL → JIT → CPU.
C# is compiled by Roslyn into IL and metadata in an assembly. The CLR/JIT compiles IL to native machine code for execution.
4. Difference between .csproj and .sln?
.csproj describes/configures one project; .sln groups projects into a solution.
5. Difference between var and dynamic?
var is compile-time type inference. dynamic defers type checking/binding to runtime.
6. Difference between ref and out?
ref requires the caller to initialize the variable; out does not, but the called method must assign it.
7. What are the four pillars of OOP?
Encapsulation, inheritance, polymorphism and abstraction.
8. Difference between readonly and const?
readonly can be assigned at declaration or instance construction; const is a compile-time constant assigned at declaration and is effectively static.
9. What does File.WriteAllText do?
Writes text to a file, replacing existing contents.
10. Why use try/catch?
To handle exceptions and respond appropriately instead of allowing an unhandled exception to terminate the operation/application.
11. Count vs Capacity in List<T>?
Count is the number of elements; Capacity is the current internal storage available before another resize may be required.
12. What is a delegate?
A type that can hold a reference to compatible method(s), allowing methods to be stored, passed, returned and invoked.
13. Action vs Func vs Predicate?
Action returns void; Func returns a value, with its last generic parameter as the return type; Predicate takes one T and returns bool.
14. Where vs Select?
Where filters elements; Select transforms/projects each element.
15. First vs FirstOrDefault?
First throws when no element is found; FirstOrDefault returns the default value when no element is found.
16. What is deferred execution?
Many LINQ queries are evaluated when enumerated/materialized rather than immediately when the query is defined.
17. Write LINQ to find Grade A students.
students.Where(s => s.Grade == "A").ToList()
18. Write LINQ to get student names.
students.Select(s => s.Name).ToList()
19. Write LINQ to find a student by ID.
students.FirstOrDefault(s => s.Id == id)
20. Explain FIFO and LIFO.
FIFO = First In, First Out → Queue. LIFO = Last In, First Out → Stack.
